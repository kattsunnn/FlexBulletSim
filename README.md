# FlexBulletSim

テニスコート上に複数カメラを並べ、バレットタイム風に視点切替を行うデモ（React + Three.js + Vite）。

## 機能
- 標準カメラパターンの適用 / 削除
- JSONインポートによるカスタムパターン追加
- パターン単位の自動FOVスケールON/OFF
- フォーカスターゲット切替（プレイヤー / ネット / 中央）
- キーボード: ← →（カメラ）/ P（パターン）/ F（フォーカス）/ R（先頭へ）

## JSON インポート手順
1. 画面右下「配置を追加」
2. JSONをドラッグ&ドロップ or ファイル選択
3. プレビュー確認 → 追加
4. 一覧から「適用」

## JSON フォーマット

### 単一パターン例
```json
{
	"patternName": "SampleLine",
	"autoScaleFOV": true,
	"cameras": [
		{ "x": 5.0, "y": 0.0, "z": 1.0 },
		{ "x": 5.0, "y": 1.5, "z": 1.0 },
		{ "x": 5.0, "y": 3.0, "z": 1.0 }
	],
	"players": [
		{ "x": 0, "y": 0, "z": -5.9 },
		{ "x": 0, "y": 0, "z": 5.9 }
	]
}
```

### 複数パターン例（最初の1件のみ使用）
```json
{
	"patterns": [
		{
			"patternName": "DenseLeft",
			"autoScaleFOV": false,
			"cameras": [
				{ "x": 5.0, "y": 0.0, "z": 1.0 },
				{ "x": 5.0, "y": 0.75, "z": 1.0 },
				{ "x": 5.0, "y": 1.5, "z": 1.0 }
			],
			"players": [ { "x": 0, "y": 0, "z": -5.9 }, { "x": 0, "y": 0, "z": 5.9 } ]
		},
		{
			"patternName": "SparseRight",
			"cameras": [ { "x": -5.0, "y": 0.0, "z": 1.0 }, { "x": -5.0, "y": 3.0, "z": 1.0 } ],
			"players": [ { "x": 0, "y": 0, "z": -5.9 }, { "x": 0, "y": 0, "z": 5.9 } ]
		}
	]
}
```

### フィールド説明
| フィールド | 必須 | 説明 |
|------------|------|------|
| patternName | Yes | 一覧表示名（重複不可） |
| autoScaleFOV | No  | 省略時 true（距離に応じFOVを相対補正） |
| positions[] / cameras[] | Yes | カメラ位置配列。positions 推奨。x=横, y=高さ(省略時0.8), z=奥行方向 |
| players[] | No | プレイヤー再配置用（0〜2要素）。指定なければデフォルト位置 |

### 動作補足
- カスタムパターン適用時: カメラ群再構築/players指定あれば即座に再配置
- ビルトインへ戻す: プレイヤー位置をデフォルトへリセット
- FOV自動/固定はパターン単位で記憶
